# Enterprise Knowledge Assistant

An AI-powered Enterprise Knowledge Assistant built with FastAPI, OpenAI, React, and a Vector Database. It enables employees to search company documents using natural language through Retrieval-Augmented Generation (RAG), providing accurate answers with source citations.

---

# Project Goal

Build an enterprise-grade AI assistant that can:

- Understand natural language questions
- Search company documents using semantic search
- Generate accurate answers using RAG
- Cite the exact source document and page
- Remember conversations
- Support multiple document formats
- Scale for enterprise environments
